## Context

当前博客使用 Next.js 15 + React 19 + TypeScript 构建，采用 shadcn/ui 组件库。首页由 `HomeHero` 和 `FeaturedPosts` 两个主要组件组成。

**现状分析:**
- `HomeHero` 组件采用双栏布局，左侧文字右侧头像
- 设计风格偏向传统博客，缺乏个人特色
- 内容定位模糊，未能体现技术专长和职业转型
- 缺少技能展示和项目亮点区域

**技术约束:**
- 保持 Next.js 15 的 App Router 架构
- 继续使用 shadcn/ui 组件库保证一致性
- 动画效果优先使用 CSS，复杂动画考虑 framer-motion
- 确保 Lighthouse 分数不下降（当前性能优秀）

## Goals / Non-Goals

**Goals:**
- 重构首页布局为多段落的叙事性设计
- 新增技能展示区，直观呈现技术栈
- 新增项目亮点区，展示代表性作品
- 新增时间线组件，讲述职业转型故事
- 保持或提升当前性能指标
- 确保移动端响应式体验

**Non-Goals:**
- 不改变博客文章系统本身
- 不添加后端功能或 API
- 不改变现有的 UI 组件库基础
- 不添加用户认证或数据库功能
- 不改变 SEO 基础结构

## Decisions

### 1. 动画方案：CSS + framer-motion 混合

**决策:** 使用 CSS 实现基础悬停效果和简单过渡，framer-motion 实现复杂滚动动画

**理由:**
- CSS 动画性能更好，适合简单效果
- framer-motion 提供更好的滚动动画和交错动画 API
- 可按需引入，避免过度增加包体积

**替代方案:**
- 纯 CSS 方案：滚动动画实现复杂，代码可维护性差
- 纯 framer-motion：增加不必要的包体积（~15KB gzipped）

### 2. 布局结构：分段式单页设计

**决策:** 采用垂直分段的单页设计，每段有明确的视觉层次

**理由:**
- 符合用户从上到下的阅读习惯
- 便于讲述"我是谁 → 我会什么 → 我做过什么 → 联系我"的故事
- 移动端友好，无需复杂的响应式重组

### 3. 配色方案：科技蓝紫渐变

**决策:** 主色调从当前粉色系改为蓝紫渐变（#6366f1 → #a855f7）

**理由:**
- 蓝紫色系更符合科技/AI 定位
- 与现有 shadcn/ui 组件的 CSS 变量系统兼容
- 保持深色模式支持

### 4. 技能展示：分类 + 进度条可视化

**决策:** 技能分为"前端核心"、"AI/ML"、"工具/其他"三类，使用进度条展示熟练度

**理由:**
- 分类清晰，便于招聘者快速定位
- 进度条提供直观的熟练度参考
- 避免星级评分过于主观

### 5. 图片资源：使用占位符 + 用户自定义

**决策:** 使用高质量占位图片，用户可替换为个人照片

**理由:**
- 即插即用体验
- 保持代码可移植性

## Risks / Trade-offs

**[性能风险] framer-motion 增加包体积**
→ 缓解：动态导入组件，仅在实际使用时加载

**[维护成本] 自定义组件增多**
→ 缓解：严格遵循 shadcn/ui 的代码风格和 TypeScript 模式

**[视觉一致性] 新增组件可能与现有 UI 不协调**
→ 缓解：复用 shadcn/ui 的 CSS 变量系统，保持设计语言一致

**[内容维护] 静态内容需要手动更新**
→ 缓解：使用清晰的注释标注可配置区域，考虑未来添加 CMS 集成

## Migration Plan

1. **阶段 1**: 创建新组件（`AnimatedHero`, `SkillShowcase`, `ProjectHighlight`, `TimelineSection`）
2. **阶段 2**: 更新 `src/app/page.tsx` 组合新组件
3. **阶段 3**: 添加全局 CSS 变量和动画样式
4. **阶段 4**: 测试响应式布局和多浏览器兼容性
5. **阶段 5**: 性能优化（懒加载、图片优化）

**回滚策略:** 保留原有 `HomeHero` 组件，Git 提交后易于回滚
